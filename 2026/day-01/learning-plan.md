# Day 01 - Introduction to DevOps & Cloud

## 1. What is your understanding of DevOps & Cloud Engineering?

**DevOps** is a way of working where developers and operations teams work together.  
It helps to build, test, and release software faster with fewer mistakes.  
The main focus is teamwork, automation, and continuous improvement.

**Cloud** means using the internet to store data and run applications.  
Instead of storing everything on your own computer or server, you can use online services.  
This allows you to access files and applications from anywhere.
