# Day 03 – Linux Commands Practice

## Process Management

- **ps** — shows the processes that are currently running.
- **top** — shows live system usage and running processes.
- **htop** — an interactive and colorful version of top that is easier to read.
- **kill <PID>** — stops a process using its Process ID.
- **killall <name>** — stops all processes with the given name.
- **nice** — runs a process with a chosen priority level.
- **systemctl** — used to start, stop, restart, or check system services.


## File System & Directory (8 commands)

- **ls** — shows files and folders in the current directory.
- **cd <dir>** — moves to another directory.
- **pwd** — shows the current directory path.
- **mkdir <dir>** — creates a new folder.
- **rm <file/dir>** — deletes a file or folder (`-r` deletes folders with contents).
- **cp <src> <dest>** — copies files or folders.
- **mv <src> <dest>** — moves or renames files or folders.
- **chmod <mode> <file>** — changes file permissions.


## Networking (7 commands)

- **ping <host>** — checks if a system or website is reachable.
- **ip addr** — shows network interfaces and IP addresses.
- **dig <domain>** — checks DNS details of a domain.
- **curl <URL>** — gets data from a website or API.
- **wget <URL>** — downloads files from the internet.
- **ssh <user@host>** — connects to another machine securely.
- **scp <src> <dest>** — securely copies files between machines.
